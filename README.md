
# My Budget Tracker

## Project Description
My Budget Tracker is a simple personal finance web application. It helps users record expenses, monitor spending, and view their remaining budget.

## Features
- View total budget.
- Add new expenses.
- Select expense categories.
- View expense history.
- Automatically calculate total expenses.
- Automatically calculate remaining balance.
- Delete expenses.
- Save expense records in browser local storage.
- Responsive design for mobile and desktop screens.

## Project Files

### index.html
Contains the structure of the Budget Tracker, including the heading, summary cards, expense form, and expense history table.

### style.css
Controls the visual design, colors, typography, spacing, forms, buttons, table, and responsive layout.

### script.js
Handles adding and deleting expenses, calculating totals, updating the remaining balance, and saving data in local storage.

### README.md
Contains project information and documentation.

## Design Choices
- Primary color: Dark Green
- Background: Light Grey
- Cards: White
- Heading font: Poppins
- Body font: DM Sans

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Browser Local Storage

## How to Run
Open `index.html` in a web browser. The Google Fonts require an internet connection.
